# AI Workplace Productivity Assistant - Novaweave

**Live Demo:** https://novaweave-ai.lovable.app/  
**GitHub Repo:** https://github.com/KhanyaKala/ai-focus-hub

## Overview
AI Workplace Productivity Assistant is a responsive web app that helps professionals and students automate daily tasks using AI. It has a modern SaaS-style dashboard with bright colours, smooth animations, and 5 AI tools built for work and study.

## Who It's For
- **Professionals:** Email writing, meeting summaries, task planning, research
- **Students:** Assignment help, study plans, emails to lecturers, research summaries

## Key Features
1. **Smart Email Generator** - Draft professional emails with Formal, Friendly, or Persuasive tones
2. **Meeting Notes Summarizer** - Turn transcripts or lecture notes into summaries and action items
3. **AI Task Planner** - Create daily/weekly schedules with priorities and time-blocking
4. **AI Research Assistant** - Get summaries, key insights, and research questions for work or school
5. **AI Chatbot** - Ask for help with prompts like "Plan my week" or "Explain a concept"

## Design
- Responsive dashboard with sidebar navigation
- Bright gradients: blue, purple, teal, pink
- Card layouts, glassmorphism, modern icons
- All AI outputs are editable with Copy, Regenerate, and Download options
